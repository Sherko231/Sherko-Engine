# Sherko Engine

Java-first 3D engine scoped for small/medium first-/third-person, physics-heavy, humorous multiplayer co-op games.

## Project documents

- [Engine scope](ENGINE_SCOPE.md) — product and architecture boundaries.
- [Roadmap](ROADMAP.md) — milestone-level plan and current focus.
- [Technical backlog](docs/roadmap/TECHNICAL_BACKLOG.md) — detailed implementation task catalog with stable task IDs and acceptance criteria.
- [Engineering references](docs/REFERENCES.md) — source map behind the roadmap.

## Current state

The repository is still at the pre-foundation stage. The current roadmap focus is **M0 / Phase 0 — Feasibility**, especially validating the production Steam/networking path before engine architecture depends on it.

Implementation work should be taken from GitHub Issues for the active phase, not directly from the entire technical backlog. Live task status belongs in GitHub Issues/Project rather than the planning documents.
